# IDA C++ SDK

\section intro_sec Introduction

This is the official reference documentation of the IDA C++ SDK. Use it to
build native components that extend IDA: plugins, processor modules, file
loaders, and debugger modules, all with full access to IDA's internals.

The C++ SDK is the right choice when you need maximum performance, tight
integration with IDA's core, or functionality that is only exposed through
the native API. See \ref pro.h for the platform macros and conventions that
apply throughout this reference.

\note Prefer Python? IDA also ships with
[IDAPython](https://python.docs.hex-rays.com/) for scripting and plugins,
and the higher-level [IDA Domain API](https://ida-domain.docs.hex-rays.com/)
built on top of it.
